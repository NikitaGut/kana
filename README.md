# かな | Kana — изучение японской азбуки

Интерактивный тренажёр для изучения хираганы (ひらがな) и катаканы (カタカナ). Знаки изучаются небольшими группами, а тесты помогают закрепить их чтение.

🚀 **[Открыть демо](https://nikitagut.github.io/kana/)**

## Возможности

- **Хирагана и катакана.** Переключайтесь между двумя японскими слоговыми азбуками.
- **Пошаговые уроки.** Азбуки разделены на строки: а, ка, са и другие. Следующая строка открывается после правильных ответов на все вопросы текущего теста.
- **Знакомство со знаками.** В каждом уроке показаны символы строки и их чтение ромадзи.
- **Тест по текущей строке.** Проверьте чтение каждого знака из открытого урока. Неправильные варианты по возможности берутся из той же строки, чтобы их нельзя было легко отсеять по первому слогу.
- **Общий тест по пройденным строкам.** Отдельная кнопка запускает перемешанный тест по всем знакам строк, которые уже пройдены в выбранной азбуке.
- **Прогресс обучения.** Боковая панель показывает доступные и закрытые строки, а также число пройденных уроков.
- **Локальное сохранение.** Прогресс хранится в браузере на этом устройстве. Его можно сбросить кнопкой «Сбросить прогресс».

## Запуск

Откройте `index.html` в браузере. Проект не требует установки зависимостей или сборки.
