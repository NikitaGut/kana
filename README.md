# かな | Kana — Изучение японской азбуки

Интерактивный веб-сервис для изучения японской азбуки (хираганы и катаканы). Обучение построено по принципу «шаг за шагом, знак за знаком» — от простых строк к более сложным, с закреплением знаний через небольшие проверки.

🚀 **[Открыть живое демо](https://nikitagut.github.io/kana/)**

## ✨ Основные возможности

*   **Два алфавита**: Поддержка изучения как Хираганы (ひらがな), так и Катаканы (カタカナ).
*   **Пошаговое обучение**: Азбука разбита на логические строки (Строка «а», Строка «ка», Строка «та» и т.д.).
*   **Интерактивные уроки**: Знакомство с новыми символами, их написанием и правильным произношением (ромадзи).
*   **Проверка знаний (Квизы)**: После изучения каждой строки предлагается мини-тест, чтобы закрепить материал. Например, выбор правильного чтения знака из четырех вариантов.
*   **Отслеживание прогресса**: Удобная боковая панель показывает текущий маршрут, изученные знаки и общий прогресс (например, 4/11 строк).
*   **Современный и минималистичный UI**: Приятная глазу цветовая гамма и понятный интерфейс, который не отвлекает от учебы.
